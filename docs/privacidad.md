# Política de Privacidad - Zoe TASA

última actualización: 7 de octubre de 2026.

## 1. Responsable

Zoe TASA es una aplicación desarrollada por Yimmy Alberto Del Valle Quintero ("el desarrollador", "nosotros").

Contacto: zoetasa.soporte@gmail.com

## 2. Resumen

Zoe TASA no recolecta, transmite, almacena en servidores ni comparte datos personales del usuario. Toda la información que la aplicación maneja permanece en el dispositivo del usuario.

## 3. Datos que NO se recolectan

Zoe TASA no recolecta:

- Nombre, correo electrónico, teléfono ni ningún dato identificador.
- Ubicación.
- Contactos, fotos, archivos ni contenido del dispositivo.
- Identificadores de publicidad ni de dispositivo.
- Estadísticas de uso, analíticas ni telemetría.
- Datos de fallos ni reportes de error.

No se requiere crear cuenta ni iniciar sesión para usar la aplicación.

## 4. Datos que la aplicación maneja localmente

La aplicación guarda en el propio dispositivo, mediante almacenamiento local, únicamente:

- Las tasas personalizadas que el usuario cree.
- Las preferencias de la aplicación (por ejemplo, cuál tasa se muestra en el widget).
- Una copia en caché de las últimas tasas descargadas, para poder mostrar información cuando no hay conexión.

Estos datos nunca salen del dispositivo y se eliminan al desinstalar la aplicación.

## 5. Servicios de terceros

Zoe TASA consulta la API pública DolarApi (https://ve.dolarapi.com) para obtener las tasas de cambio oficiales del Banco Central de Venezuela (BCV). Esta consulta es una petición HTTPS genérica desde la aplicación a ese servicio. DolarApi no recibe ningún dato personal del usuario; únicamente recibe la petición con la dirección IP pública del dispositivo, tal como cualquier petición a un servicio web.

No se integran servicios de analítica, publicidad, rastreo ni redes sociales.

## 6. Permisos

La aplicación solicita un único permiso de Android: acceso a Internet (android.permission.INTERNET), necesario exclusivamente para consultar las tasas de cambio.

## 7. Widget de pantalla de inicio

El widget de Zoe TASA muestra la tasa seleccionada por el usuario en la pantalla de inicio del teléfono. Los datos que muestra el widget se guardan localmente en el dispositivo. No se transmite ningún dato del usuario ni de su pantalla de inicio a ningún servidor.

## 8. Menores de edad

Zoe TASA no está dirigida específicamente a menores de edad y no recolecta datos de ningún usuario, incluidos menores.

## 9. Cambios a esta política

Cualquier cambio a esta política de privacidad se reflejará en este mismo documento, actualizando la fecha indicada al inicio. Se recomienda al usuario revisar periódicamente esta página.
