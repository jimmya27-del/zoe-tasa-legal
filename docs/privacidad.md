# Politica de Privacidad - Zoe TASA

Ultima actualizacion: 7 de octubre de 2026.

## 1. Responsable

Zoe TASA es una aplicacion desarrollada por Yimmy Alberto Del Valle Quintero ("el desarrollador", "nosotros").

Contacto: zoetasa.soporte@gmail.com

## 2. Resumen

Zoe TASA no recolecta, transmite, almacena en servidores ni comparte datos personales del usuario. Toda la informacion que la aplicacion maneja permanece en el dispositivo del usuario.

## 3. Datos que NO se recolectan

Zoe TASA no recolecta:

- Nombre, correo electronico, telefono ni ningun dato identificador.
- Ubicacion.
- Contactos, fotos, archivos ni contenido del dispositivo.
- Identificadores de publicidad ni de dispositivo.
- Estadisticas de uso, analiticas ni telemetria.
- Datos de fallos ni reportes de error.

No se requiere crear cuenta ni iniciar sesion para usar la aplicacion.

## 4. Datos que la aplicacion maneja localmente

La aplicacion guarda en el propio dispositivo, mediante almacenamiento local, unicamente:

- Las tasas personalizadas que el usuario cree.
- Las preferencias de la aplicacion (por ejemplo, cual tasa se muestra en el widget).
- Una copia en cache de las ultimas tasas descargadas, para poder mostrar informacion cuando no hay conexion.

Estos datos nunca salen del dispositivo y se eliminan al desinstalar la aplicacion.

## 5. Servicios de terceros

Zoe TASA consulta la API publica DolarApi (https://ve.dolarapi.com) para obtener las tasas de cambio oficiales del Banco Central de Venezuela (BCV). Esta consulta es una peticion HTTPS generica desde la aplicacion a ese servicio. DolarApi no recibe ningun dato personal del usuario; unicamente recibe la peticion con la direccion IP publica del dispositivo, tal como cualquier peticion a un servicio web.

No se integran servicios de analitica, publicidad, rastreo ni redes sociales.

## 6. Permisos

La aplicacion solicita un unico permiso de Android: acceso a Internet (android.permission.INTERNET), necesario exclusivamente para consultar las tasas de cambio.

## 7. Widget de pantalla de inicio

El widget de Zoe TASA muestra la tasa seleccionada por el usuario en la pantalla de inicio del telefono. Los datos que muestra el widget se guardan localmente en el dispositivo. No se transmite ningun dato del usuario ni de su pantalla de inicio a ningun servidor.

## 8. Menores de edad

Zoe TASA no esta dirigida especificamente a menores de edad y no recolecta datos de ningun usuario, incluidos menores.

## 9. Cambios a esta politica

Cualquier cambio a esta politica de privacidad se reflejara en este mismo documento, actualizando la fecha indicada al inicio. Se recomienda al usuario revisar periodicamente esta pagina.
